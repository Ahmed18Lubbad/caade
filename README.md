# موقع الجمعية التعاونية للتنمية الزراعية والبيئة – غزة

الموقع مبني باستخدام **Next.js وReact**، مع تصدير ثابت للصفحات. لذلك يعمل الموقع المنشور كملفات HTML وCSS وJavaScript وصور ثابتة ولا يحتاج إلى خادم Node.js.

## التشغيل والتطوير

يتطلب التطوير والبناء Node.js 20.9 أو أحدث وnpm. بعد تثبيت الاعتماديات مرة واحدة، شغّل:

```powershell
npm install
npm run dev
```

افتح `http://localhost:3000/` أو `/ar/` أو `/en/`. لإنشاء النسخة الجاهزة للنشر شغّل `npm run build`، ثم ارفع محتويات مجلد `out/` إلى استضافة ملفات ثابتة تدعم HTTPS. لا تستخدم `npm start` لتشغيل النسخة المنشورة الثابتة.

## المحتوى والملفات

- `public/data/ar.json` و`public/data/en.json`: محتوى الموقع باللغتين.
- `public/media/`: الصور والشعارات والتقارير والملفات المنشورة.
- `public/site.css` و`public/subpage.css`: التنسيقات.
- `public/site.js` و`public/subpage.js` و`public/detail.js`: تفاعلات الواجهة الحالية.
- `app/`: مسارات Next.js لتوليد الصفحة الرئيسية والصفحات الفرعية والتفاصيل لكل لغة.
- `src/templates/`: نصوص هيكل الصفحات الحالية التي تعرضها مكونات Next.js.

اسم المؤسسة في الواجهة الرئيسية يؤخذ من `name` في `ar.json`، ومن `profile.name` في `en.json`. لتغيير النبذة القصيرة تحت الاسم، عدّل `profile.heroIntro` في الملفين.

## إضافة البرامج والمشاريع والصور أو حذفها

لا توجد لوحة إدارة ولا حاجة إلى Backend. المحتوى موجود في ملفي JSON ويمكن تعديله بمحرر نصوص عادي مثل VS Code:

1. افتح `public/data/ar.json` و`public/data/en.json`.
2. أضف العنصر داخل المصفوفة المناسبة (`programs` أو `projects` أو `gallery`) في الملفين. أبقِ قيمة `id` واحدة ومتطابقة للعنصر العربي والإنجليزي.
3. احفظ الصور أولًا داخل `public/media/`، ثم ضع مسارها الذي يبدأ بـ`/media/` في JSON.
4. احذف العنصر من المصفوفة نفسها في الملفين لإزالته من الموقع. لا تحذف الفاصلة بين العناصر المجاورة.
5. أثناء التطوير، حدّث المتصفح بعد الحفظ. قبل النشر، شغّل `npm run build` وارفع محتويات `out/` من جديد.

### إضافة برنامج

انسخ عنصرًا داخل مصفوفة `programs` وغيّر الحقول. لا تحتاج البرامج إلى صورة:

```json
{
  "id": "strategic-6",
  "title": "عنوان البرنامج",
  "description": "وصف موجز للبرنامج.",
  "icon": "06"
}
```

اكتب النص العربي في `ar.json` والترجمة الإنجليزية في `en.json` مع إبقاء `id` متطابقًا.

### إضافة مشروع

```json
{
  "id": "project-example-01",
  "category": "مشروع منفذ",
  "title": "اسم المشروع",
  "description": "نبذة عن المشروع ونتائجه.",
  "date": "2026-10-24",
  "image": "/media/projects/project-example.jpg",
  "gallery": "/media/projects/project-example-02.jpg\n/media/projects/project-example-03.jpg",
  "url": ""
}
```

`image` هي الصورة الرئيسية. حقل `gallery` اختياري؛ ضع مسار كل صورة في سطر مستقل بين علامتي الاقتباس. يمكن ترك `url` فارغًا أو وضع رابط مصدر خارجي.

### إضافة صورة إلى معرض الصور

```json
{
  "id": "gallery-example-01",
  "title": "وصف الصورة",
  "image": "/media/gallery/gallery-example.jpg"
}
```

للحذف، احذف العنصر ذي `id` المطلوب من مصفوفته في ملفي اللغة. احذف ملف الصورة من `public/media/` فقط إذا لم يكن مستخدمًا في أي مشروع أو خبر أو موضع آخر.

> تذكّر: ملفات JSON حساسة للفواصل وعلامات الاقتباس. إذا تعطل تحميل المحتوى بعد التحرير، راجع أن كل عنصر مفصول بفاصلة وأن آخر عنصر في المصفوفة لا تنتهي قيمته بفاصلة.

## النشر

ارفع محتويات `out/` إلى استضافة ثابتة مثل GitHub Pages أو Netlify أو Cloudflare Pages. لا تحتاج الاستضافة إلى Node.js؛ Node.js مطلوب فقط على جهاز التطوير لتشغيل Next.js وإنشاء التصدير الثابت.
