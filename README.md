# الجمعية التعاونية للتنمية الزراعية والبيئة – غزة

موقع عربي متجاوب مبني بهيكل تحريري يشمل التعريف، البرامج، الأخبار، قصص الأثر، معرض الصور، الفيديو، المشاريع، التقارير، والشركاء.

تستخدم الواجهة Bootstrap 5.3.3 بنسخة RTL تُقدَّم محليًا من المشروع، مع أنماط مخصصة لهوية الجمعية. يلزم `npm install` لتثبيت مكتبات Bootstrap وNodemailer.

## التشغيل محليًا

يتطلب Node.js 20 أو أحدث.

قبل أول تشغيل، أنشئ ملف الإعدادات المحلي إن لم يكن موجودًا، ثم عيّن اسم مستخدم الإدارة وكلمة مرور قوية وسر جلسة عشوائيًا طويلًا. لا تترك هذه القيم فارغة أو تستخدم نص المثال كما هو:

```powershell
if (-not (Test-Path .env)) { Copy-Item .env.example .env }
[Convert]::ToHexString([Security.Cryptography.RandomNumberGenerator]::GetBytes(32))
```

انسخ ناتج الأمر إلى `ADMIN_SESSION_SECRET` في `.env`، وأدخل بيانات دخول الإدارة في `ADMIN_USERNAME` و`ADMIN_PASSWORD`.

```powershell
npm install
npm start
```

افتح `http://127.0.0.1:3000` في المتصفح. غيّر رقم المنفذ بتعيين متغير البيئة `PORT` قبل التشغيل.

### التواصل عبر الموقع

زر التواصل يفتح Gmail برسالة جديدة موجّهة إلى `caade.coop@gmail.com`؛ لا يحتاج هذا الزر إلى إعداد SMTP.

تُستخدم إعدادات SMTP الاختيارية لإرسال رسائل إعادة تعيين كلمة مرور إدارة المحتوى. استخدم كلمة مرور تطبيق أو بيانات اعتماد مخصصة للبريد، ولا تضع كلمة مرور حسابك الشخصية في `.env` أو تشاركها.

## الترجمة التلقائية إلى الإنجليزية

تُترجم النصوص العربية التي تضيفها أو تعدّلها من لوحة الإدارة إلى الإنجليزية عند الحفظ، وتُحفظ النسختان معًا باستخدام LibreTranslate محليًا، من دون حساب أو مفتاح API. ثبّت [Python 3.8 أو أحدث](https://docs.python.org/3/using/windows.html)، ثم افتح نافذتي PowerShell داخل مجلد المشروع.

في النافذة الأولى ثبّت الخدمة وشغّلها على الجهاز المحلي:

يفضّل استخدام Python 3.12 لتشغيل LibreTranslate على Windows. إذا كان الأمر `libretranslate` غير معروف، شغّل الملف التنفيذي من مجلد Scripts مباشرة. غيّر مسار Python أدناه إذا ظهر مجلد تثبيت مختلف في مخرجات `pip`.

```powershell
$env:XDG_DATA_HOME = "$env:LOCALAPPDATA\LibreTranslate\data"
$env:XDG_CONFIG_HOME = "$env:LOCALAPPDATA\LibreTranslate\config"
$env:XDG_CACHE_HOME = "$env:LOCALAPPDATA\LibreTranslate\cache"
& "$env:LOCALAPPDATA\Python\pythoncore-3.12-64\Scripts\libretranslate.exe" --host 127.0.0.1 --port 5000 --load-only ar,en
```

نفّذ التثبيت مرة واحدة فقط باستخدام `py -3.12 -m pip install libretranslate`. ثبّت Python أولًا باستخدام `py install 3.12` إذا لم يكن مثبتًا. اترك نافذة الخدمة مفتوحة؛ قد يستغرق تنزيل نماذج العربية والإنجليزية وقتًا في أول تشغيل.

على Windows، إذا خرجت الخدمة مباشرة برمز `-1073741819`، أعد تثبيت إصدار متوافق من ONNX Runtime ثم شغّل الخدمة مجددًا:

```powershell
py -3.12 -m pip install --force-reinstall "onnxruntime==1.20.1" "numpy==1.26.4" "packaging==23.1" "sentencepiece==0.2.0"
```

إذا بدأت LibreTranslate لكنها أُغلقت عند تحميل نموذج الترجمة، ثبّت إصدار CTranslate2 المتوافق مع Windows. يتطلب هذا الإصدار أيضًا `setuptools` أقدم من 81:

```powershell
py -3.12 -m pip install --force-reinstall --no-deps "ctranslate2==4.5.0" "setuptools<81"
```

بعد التثبيت، شغّل `start-translation.cmd` من مجلد المشروع واترك نافذته مفتوحة أثناء استخدام الموقع. يعرض الملف رسائل الخطأ ورمز الخروج إذا توقفت الخدمة.

في النافذة الثانية شغّل الموقع:

```powershell
node server.js
```

يستدعي الموقع `http://127.0.0.1:5000/translate`. نموذج العربية والإنجليزية يُنزّل عند تشغيل الخدمة أول مرة؛ احفظ النافذتين مفتوحتين أثناء استخدام الترجمة. يدعم LibreTranslate زوج العربية والإنجليزية مباشرة، والتثبيت المحلي يبقي طلبات الترجمة على جهازك. [التثبيت الرسمي](https://docs.libretranslate.com/guides/installation/) · [واجهة الترجمة](https://docs.libretranslate.com/api/operations/translate/) · [اللغات المدعومة](https://docs.libretranslate.com/guides/supported_languages/).

## إدارة المحتوى والموقع

بعد تشغيل الخادم، افتح الموقع واضغط «إدارة المحتوى» أسفل الصفحة. من تبويب «بيانات الجمعية» أضف الشعار والنبذة والرؤية والرسالة والقيم والإحصاءات وبيانات التواصل والعنوان على الخريطة وساعات العمل. ومن تبويب «الأقسام والمحتوى» أضف البرامج والأخبار والقصص والصور والفيديوهات والمشاريع والتقارير والشركاء، أو عدّل العناصر واحذفها. يمكن إضافة نص كامل للخبر لعرضه في صفحة تفاصيل مستقلة. الأخبار والمشاريع قابلة للتصفية، والتقارير السنوية والشركاء ظاهرة في أقسام مخصصة. رفع الشعار يحفظه مباشرة ويعرضه بجانب اسم الجمعية في رأس الموقع وتذييله.

يمكن رفع الصور بصيغ JPG وPNG وWEBP، ورفع ملفات PDF للتقارير، بحد أقصى 8 ميغابايت للملف. تُحفظ البيانات في `data/site-data.json` والملفات المرفوعة في مجلد `media/`. ينشئ الخادم نسخة احتياطية عند أول تشغيل، ثم أسبوعيًا، ويحفظ آخر 12 نسخة داخل `backups/`. أوقف الخادم قبل استعادة نسخة احتياطية، ثم استعد محتويات مجلدي `data/` و`media/` من النسخة المطلوبة.

صفحات تفاصيل الأخبار والمشاريع تستخدم المسارات `/news/{id}` و`/projects/{id}`. يجب تشغيل الخادم عبر `npm start` لتعمل هذه الصفحات ونسخ الموقع المجدولة.

## ترتيب ملفات المشروع

- `server.js`: خادم HTTP وواجهات API وتسجيل الدخول وإدارة الملفات.
- `index.html` و`site.js` و`site.css`: الصفحة الرئيسية ومنطقها وتنسيقها.
- `admin.html` و`admin.js`: لوحة إدارة محتوى الموقع.
- `subpage.html` و`subpage.js` و`subpage.css`: الصفحات التعريفية الفرعية.
- `detail.html` و`detail.js`: صفحة تفاصيل الأخبار والمشاريع.
- `data/site-data.json`: محتوى الموقع القابل للتحرير.
- `media/`: صور ووسائط الموقع التي يحتاجها العرض.
- `package.json` و`package-lock.json`: تعريف الاعتماديات وأوامر التشغيل.
- `.env.example`: نموذج إعدادات؛ انسخه إلى `.env` وضع بياناتك الخاصة محلياً.

## رفع المشروع إلى GitHub

ارفع ملفات المشروع ومجلد `data` و`media` إلى مستودع GitHub. لا ترفع `.env` أو `node_modules` أو `backups` أو مجلدات التخزين المؤقت. لإرفاق نسخة مضغوطة جاهزة، استخدم `caade-gaza-website-github.zip` الموجود بجانب ملفات المشروع.

بعد تنزيل المستودع، شغّل `npm install` ثم `npm start`. يجب إعداد `.env` محلياً قبل تشغيل لوحة الإدارة.
